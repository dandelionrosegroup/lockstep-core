# Lockstep Core v0.1.0 — First Public Release

Chain-based project tracking for Human+AI collaboration. An MCP server that gives your AI assistant persistent memory across sessions.

## What's in this release

- **40 tools + 5 commands** for full project lifecycle management
- **Chain-based tracking** — sessions link together so nothing gets lost between conversations
- **Structured handoffs** — decisions, context, and next steps transfer seamlessly
- **Capacity tracking** — growth stages that make invisible progress visible
- **Advisory, not enforcing** — the protocol flags and explains, never blocks
- **Fully local** — all data stored as YAML on your machine. No network. No telemetry. No data collection.

## Install

1. Download `lockstep-chain-protocol.mcpb` from the assets below
2. Open **Claude Desktop** → **Settings** → **Extensions**
3. Click **Install Extension** and select the downloaded `.mcpb` file
4. When prompted, choose a data directory (default: `~/.lockstep/data`)
5. Start a conversation and try: *"Create a new initiative called 'My First Project' with the vision 'Learn how Lockstep works'"*

## Who is this for?

Anyone using AI coding assistants who wants structured session continuity. Especially useful for neurodivergent individuals who benefit from external scaffolding — Lockstep makes the invisible work of executive function visible and trackable.
